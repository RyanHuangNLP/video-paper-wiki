# PRD：新增 multiply(a, b) 函数

## 背景
测试项目当前需要补充一个基础乘法能力，用于返回两个输入数值的乘积，并通过单元测试保障行为正确。

## 目标
新增 `multiply(a, b)` 函数，接收两个参数 `a` 和 `b`，返回两者相乘的结果。

## 范围
- 新增或暴露 `multiply(a, b)` 方法。

- 不提交 Git。

## 功能需求
1. `multiply(a, b)` 应返回 `a * b` 的结果。

3. 函数行为应保持简单、可预测，不引入额外副作用。
