Training Recipe SANA-Video 2.0 uses 5B and 14B models with the same hybrid design. The 5B production recipe spans data curation, a resolution/duration curriculum, and preference-based post-training (Figure 3). The 40-layer 14B run uses the same core flow-matching and hybrid-attention formulation with scale-specific pre-training settings on 384×B200 GPUs. Beyond the architecture, the recipe specifies how the corpus is transformed into progressively cleaner supervision, how noise levels are sampled, and how resolution and duration are increased. We describe these components because they are part of the method. The recipe was selected jointly rather than component-wise ablated.
