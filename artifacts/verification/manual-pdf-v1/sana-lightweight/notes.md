# SANA-Video 2.0 阅读笔记

来源：用户提供的论文 PDF；本文按 PDF 文件页码引用。[分页原文](source.md)

## 一句话结论

SANA-Video 2.0 用大部分线性注意力层降低视频 token 混合开销，用少量 softmax 层补充表达能力，再通过跨深度的 Attention Residuals 复用这些特征。[第 1–4 页](source.md#page-1)

## 研究问题与方法

长视频和高分辨率会增加 token 数量，全 softmax 注意力的二次开销随之扩大。纯线性注意力将信息压缩到固定大小状态中，表达能力又可能受限。论文采用 3:1 的线性/softmax 比例，每四层插入一个 softmax 层；通过从头训练的低分辨率代理实验选择这一折中。[第 2、3、8 页](source.md#page-2)

Block Attention Residuals 将完成的块特征提供给后续层。视频版使用跨深度共享的路由查询，并省去单独的扩散时间步条件。论文在同一检查点的开关实验中报告，深层状态有效秩平均提高约 11.7%；这是实验观察，不是普遍的理论保证。[第 4、10 页](source.md#page-4)

## 架构与训练

- 5B 配置：32 层，宽度 2,560；14B 配置：40 层，宽度 4,096，实际参数量 14.25B。[第 7 页](source.md#page-7)
- 使用 LTX-VAE 2.3 的潜表示、Gemma-2-2B-IT 文本特征和逐层交叉注意力；FFN 使用不带卷积的 SwiGLU。[第 3 页](source.md#page-3)
- 混合骨干从头训练，训练流程包括数据筛选、分辨率/时长课程、自蒸馏以及偏好后训练；不能据此推断 VAE 和文本编码器也都从零训练。[第 2、5–7 页](source.md#page-5)

## 怎样理解性能数字

| 论文报告 | 对应设置与含义 |
| --- | --- |
| VBench Total 84.30；13.2 秒 | 480×832×81，40 步，单 H100 的报告结果。 |
| 约 3.2 倍 | 720p/60 秒形状下，与匹配的全 softmax 基线比较 DiT 前向速度；不等于端到端生成速度。 |
| 3.58 倍 | 单 B200、720p/8 秒的完整 Sol-Engine 加速：62.65 秒降到 17.52 秒。单 H100 对应表中为 2.84 倍。 |
| 120 倍 | 论文首页的单 H100、720p/5 秒最终系统与 Wan 2.2-A14B 的比较，包含系统优化，不能全部归因于注意力架构。 |

依据：[第 1、8–12 页](source.md#page-8)。上述为作者报告，本次没有复现视频模型训练或速度基准。

## 阅读时需要保留的边界

保留 25% softmax 层意味着整体仍含二次复杂度项，不能把整个架构表述为严格 O(N)。文中的长时长速度测试也不能单独证明同等时长视频的生成质量。当前文本提取可支持文字阅读与页码引用，图中细节、公式排版和表格对齐仍应对照原 PDF。[第 3、9–10 页](source.md#page-3)
