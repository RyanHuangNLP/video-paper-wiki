# 混合注意力如何降低视频生成成本

长视频生成的一个主要成本来自大量时空 token 之间的注意力计算。SANA-Video 2.0 采用以线性注意力为主的骨干，并按 3:1 比例加入 softmax 层，在计算效率与表达能力之间取得折中。周期性的 softmax 层补充细粒度交互，Attention Residuals 则沿深度传递已完成块的特征，帮助后续层复用这些信息。[1，第 2–4 页]

论文分别训练了 5B 和 14B 配置。作者报告，5B 模型在单 H100、480×832×81、40 步设置下取得 84.30 的 VBench Total，并用 13.2 秒完成生成。面向更长序列，与匹配的全 softmax 骨干相比，720p/60 秒形状下的 DiT 前向获得约 3.2 倍速度提升。[1，第 1、7–10 页]

部署收益还来自内核优化、扩散缓存和稀疏注意力。Sol-Engine 在单 B200、720p/8 秒设置中将端到端时间由 62.65 秒降到 17.52 秒。因此，评估该工作的贡献时，应将骨干设计和系统优化的收益分别说明，并保留硬件、分辨率、时长和采样步数等比较条件。混合结构仍包含 softmax 层，也不宜被概括为整体严格线性复杂度。[1，第 3、11–12 页]
