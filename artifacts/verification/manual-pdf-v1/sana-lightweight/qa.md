# SANA-Video 2.0 引用问答

## 为什么不直接全部用线性注意力？

线性注意力把跨 token 的信息压缩到固定大小的状态中，可能限制细粒度时空对应关系的表达。论文因此保留周期性的 softmax 层，补充线性状态难以表达的交互；不是认为线性注意力本身没有价值。[原文第 2–3 页](source.md#page-2)

## AttnRes 在这里解决什么问题？

它沿网络深度聚合已完成块的特征，使后续线性层能够复用包含 softmax 更新的信息。它与在 token 维度混合信息的注意力承担不同工作。[原文第 4 页](source.md#page-4)

## “快 120 倍”和“快 3.2 倍”是否冲突？

不冲突，两者比较的对象和计时范围不同。约 3.2 倍来自长视频形状下、匹配骨干的 DiT 前向比较；120 倍来自最终系统与 Wan 2.2-A14B 的特定端到端场景比较。讨论架构收益时应优先引用匹配基线的测量，不能将两个倍数混用。[原文第 1、9–12 页](source.md#page-9)

## 是否可以说整个模型具有严格线性复杂度？

不能。论文仍保留 softmax 层，它们包含 O(N²) 项。“以线性注意力为主”和“整体严格线性复杂度”是不同的判断。这里的收益应结合实际序列长度和测量结果描述。[原文第 3 页](source.md#page-3)

没有。本次验证的是用户 PDF 可提取为分页文本，回答可指向相应原文页。视频质量、训练细节和性能数字仍属于论文报告；仅靠阅读文本不能完成实验复现。
