# Cursor App 的 Computer Use 备用流程

用户要求保留界面启动方式。本协议提供同一已授权工作包的技术备用入口；不改变任何
权限、安全审批、配额、模型选择或产品范围。主控负责判断故障类别，再交一位现有 Luna 执行。

## 何时切换

| CLI 结果 | 处理 |
|---|---|
| 可执行文件无法启动、崩溃、输出协议损坏，或已确认结束的连接故障，且未出现权限或安全拒绝 | 记录原错误，完成停写和目录核对后，可直接切换 GUI，无需用户再次授权同一普通任务 |
| 超时但可能仍在执行，或无法确认旧任务停止 | 先核对已有 PID、会话和交接；确认前不启动第二个 Builder |
| 自动审批、安全、权限、认证、内容政策或配额拒绝 | 保留拒绝记录，通过相应正常授权、认证或恢复流程解决；不使用 GUI、复制粘贴、另一模型或入口执行被拒绝的同一操作 |
| 原因不明 | 暂停受影响的启动并核实原因；不按普通技术故障处理 |

只有技术故障允许自动切换。用户同意备用入口不等于解除一次具体的审批拒绝。
此前 T4 的自动审批拒绝记录保留，不可改标为技术故障或通过本协议重放。

## 启动前的所有权

1. 确认该工作包仍未完成，读取最新 CURRENT、冻结任务和正式 handoff/ready；不得仅凭
   Cursor 侧栏的旧任务、Needs attention 或草稿内容恢复历史工作。
2. 核对原 lane、source realpath、目录身份、HEAD、允许路径及提示词 SHA-256。确认旧 CLI
   进程退出、旧 GUI Builder 停写，并最终化其原始记录。已有 lease 不自动删除或超时抢占。
3. GUI 控制器使用独占创建目录的方式取得同一
   `artifacts/verification/manual-pdf-v1/lightweight-workflow-v2/terminal-N/controller/active-lease`。
   该目录与 `run_cursor.py` 共用，确保 CLI 的原子创建会拒绝已有 GUI 所有者。
   在其中写入 GUI 身份记录：mode、owner、lane、run-id、parent_cli_run_id、failure_class、source、提示词摘要及可观察的
   app/window/chat 标识；未知字段写 unknown，不把临时 shell PID 当作 GUI 任务 PID。
4. 同时独占创建 `artifacts/verification/manual-pdf-v1/lightweight-workflow-v2/gui-active-lease`，
   保存相同 owner/run-id。
   整个 GUI 任务只有一个桌面操作所有者；其他 lane 可继续独立 CLI 工作。任何获取失败
   都停止本次 GUI 启动，保留已有所有者；部分获取须由本次所有者核对身份后处理。
   这些是协调锁，不是 OS 权限边界；此文档不声称已有常驻 GUI 锁管理服务。

## 界面启动与观察

使用 Computer Use 的原生应用接口打开或选择 Cursor。每次依据刚读取的窗口、控件或
截图操作，不使用旧坐标盲点；桌面焦点或窗口发生变化时重新读取状态。

选择经核验的 source 工作目录与对应任务。复用现有聊天必须能验证它属于同一 lane 和
同一断点，否则建立明确的新聊天。核对 Grok 4.6、Extra High、Fast 的实际界面设置，
并与已核验的 `cursor-grok-4.6-xhigh-fast` 映射一致；仅看到 Extra High Fast 不能证明
模型身份。保留原审批设置；不能静默改模型、关闭审批或点击 Apply/Merge。
如果无法核实精确模型或 source 工作目录，不填入或发送提示词；记录本次阻塞，
按所有者和目录身份核对后仅释放本次持有的 lease。

将已冻结 UTF-8 提示词的完整内容填入编辑框（可使用 Computer Use 的粘贴/填入能力），
发送前回读并核对内容、目标聊天、工作目录和模型。只传入本任务已授权的源码、测试、
说明和必要日志，不附带凭据或其他项目材料。点击发送一次后确认用户消息实际出现并
记录运行状态；结果不明时先观察，不重复发送。出现任何具体审批拒绝，停止该操作并保留原因。

约每 30 秒观察已有 GUI 任务和增量输出，按主协议通知主控。用户正在操作桌面或无法
核实目标时先暂停 UI 动作。不要把按钮状态、终端文字、模型自报完成当作源码验收。

## 交接与恢复

每次 GUI 尝试保留新的记录目录：触发故障原文、failure_class、parent_cli_run_id、提示词及摘要、
实际 source/模型/会话观察、时间戳、必要界面证据和 Builder 交接路径。未观察到的
CLI 退出码、模型响应元数据或 GUI chat ID 不伪造。

Builder 仍须产出约定的 files/checks/report/handoff/ready，停写后交主控独立核验。
只有确认该 GUI 任务停写且证据最终化，原所有者才按 owner/run-id/目录身份释放自己
持有的两处 lease。中断后先恢复这些记录并检查实际任务，不抢锁、不重发已提交任务。

工作包完成后停止。备用入口的增加不会重新执行已经验收的产品代码，也不会自动启用
暂停中的心跳；下次有已授权且尚未完成的工作包时才使用。
